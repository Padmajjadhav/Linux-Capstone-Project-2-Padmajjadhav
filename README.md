# Linux-Capstone-Project-2-Padmajjadhav
Linux Capstone Project 2 — Nginx web server setup, firewall configuration, log monitoring, network commands, health-check automation, and Nginx management using Bash scripts on Amazon Linux 2023.
Reflection

This Linux Capstone Project 2 helped me understand the practical work involved in setting up and maintaining a Linux web server. I used Amazon Linux 2023 on an AWS EC2 instance and configured Nginx as the web server. Nginx is a lightweight and high-performance web server that can serve static web pages, handle HTTP requests, and also work as a reverse proxy and load balancer. Apache is another popular web server, but Nginx uses an event-driven architecture that is designed to handle many simultaneous connections efficiently. Apache traditionally uses process or thread-based approaches, although it also supports different processing models. Through this project, I learned how to install, configure, start, stop, and monitor Nginx.

The firewall provides an important layer of protection for the server. It controls which network ports are allowed to accept connections. In this project, HTTP traffic on port 80 and SSH traffic on port 22 were allowed, while unnecessary ports such as port 8080 were blocked. This reduces the attack surface and prevents unauthorized network access to services that should not be publicly available.

The health check script can help prevent downtime by automatically checking important server conditions. It checks whether Nginx and firewalld are running, verifies HTTP and SSH ports, checks disk usage and memory availability, and tests the HTTP response. If Nginx or firewalld is not running, the script attempts to restart the service. The script is also scheduled through cron so that these checks can be performed automatically.

For a production-ready monitoring system, I would add centralized log management, email or mobile alerts, CPU and memory monitoring, SSL certificate monitoring, disk-space alerts, service failure notifications, and a monitoring platform such as Prometheus with Grafana. I would also improve security by restricting SSH access, using HTTPS, applying regular security updates, and implementing automated backups. Overall, this project gave me practical experience with Linux administration, web server management, networking, firewall configuration, logging, shell scripting, and automation.
